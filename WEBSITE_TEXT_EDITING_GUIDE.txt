BALTIC WEBSITE — GENERAL TEXT EDITING GUIDE
============================================

Project root: balticweb/
Website source: source/
Generated website: build/html/

IMPORTANT
---------
Edit files under source/, not build/html/. Files in build/html/ are generated by
Sphinx and will be overwritten the next time the website is built.

The examples/, tutorials/, tags/, and uses/ RST pages are also generated by the
scripts in scripts/. Edit their source inputs identified below, then regenerate
the pages.

WEBSITE FILE MAP
----------------

source/
  conf.py                         Site identity, version, theme, navigation config
  index.rst                       Root Sphinx document and page tree

  _templates/
    landing.html                  All visible homepage editorial text
    index.html                    Inserts landing.html into the homepage
    gallery.html                  Reusable gallery markup and title/subtitle fields
    remove_index.html             Template override
    pydata_sphinx_theme/...       Navigation template override

  _data/
    examples_description.txt      Editable Examples landing description
    tutorials_description.txt     Editable Tutorials landing description
    content_metadata.json         Example/tutorial tags and categories

  baltic-examples/                Original example code, data, images, README text
  baltic-tutorials/               Original tutorial code and images
  baltic-uses/baltic-uses.bib     Original "As seen in" publication records

  examples/                       Generated Examples .rst pages; do not hand-edit
  tutorials/                      Generated Tutorials .rst pages; do not hand-edit
  tags/                           Generated tag .rst pages; do not hand-edit
  uses/                           Generated publication page; do not hand-edit

  _static/
    css/                          Website styling (not normal editorial text)
    js/ and *.js                  Website behavior (not normal editorial text)
    images/                       Icons and site images
    examples/                     Generated/copied example assets
    tutorials/                    Generated/copied tutorial assets
    vendor/                       Third-party libraries; do not edit

scripts/
  build_examples.py               Generates example landing/detail pages
  build_tutorials.py              Generates tutorial landing/detail pages
  build_tags.py                   Generates tag pages
  build_uses.py                   Generates publication page from the .bib file
  build_rotator_assets.py         Generates homepage image-rotator data
  content_metadata.py             Reads/validates tags and metadata
  sync_upstream_content.py        Synchronizes upstream content

build/html/                        Fully generated website output; do not edit

make.bat / Makefile               Website build commands
balticweb_env.yml                 Build environment/dependencies
examples_tree.txt                 Existing example-content file tree


FILES THAT SHOULD USUALLY NOT BE EDITED
---------------------------------------

  build/html/**                    Generated final HTML/assets
  source/examples/**               Generated from source/baltic-examples
  source/tutorials/**              Generated from source/baltic-tutorials
  source/tags/**                   Generated from metadata
  source/uses/index.rst            Generated from baltic-uses.bib
  source/_static/vendor/**         Third-party code
  source/_static/*.min.js          Third-party/minified code
  **/__pycache__/**                Python bytecode cache


AFTER EDITING
-------------

Homepage/conf.py text:
  Rebuild the Sphinx site.

Examples description, source items, or tags:
  Run the examples generator, then the tags generator, then rebuild Sphinx.

Tutorials description, source items, or tags:
  Run the tutorials generator, then the tags generator, then rebuild Sphinx.

Publication records:
  Run the uses generator, then rebuild Sphinx.

Line numbers in this guide describe the files as they existed when this guide
was created. They may shift after edits; search for the nearby heading or text
shown in this guide if a line number no longer matches.
